1. Monday live test

Use the shop PC that will stay in the room. Phone browsers are a preview, not the gradebook.

  1. Unlock with the PIN you set (Lock → Set teacher PIN). Never 1111.
  2. Admin → Modules → Fake data Off (gold chip gone).
  3. Admin → Records → Snapshot now “Before Monday roster”.
  4. Records → Cloud → mint / confirm the desk key. Write it in the planner. Not the PIN.
  5. Tap Save / Push now on Cloud so this PC is on the internet. If this PC shows 0 workers and you already have names in the cloud, Pull — do not Push.
  6. Download JSON desk backup and Google book. Put both in a private Drive folder. Google book is an archive spreadsheet — it does not sync live. Open with File → Open in Drive as a Sheet.
  7. Records → Roster: paste Last, First, Period. The paste mints Shop IDs and aliases, then the real names are dropped. A snapshot is taken first.
  8. Snapshot again “After P1 import”. Cloud Save. Download JSON into the same Drive folder.
  9. Open the wall: aliases only. Web: class code, then Shop ID from the paper.
  10. Teach: type Ask / Do. Flip to Deck — same words. Score Crew A on one row (name + 3 / 2 / 1).
  11. Theme matrix: apply each Wall look and ROLL THE DICE, then tap Web, Help, Lock, Cog, language, NOW.

If a second computer shows 0 workers, do not Push. The desk will refuse to auto-overwrite a cloud roster with an empty PC. Pull with the desk key, or restore a snapshot on the shop PC.

5. PlanIt → Teach → Deck → Wall

One write. Type Ask / Do / Agenda / Objective on Teach (or Edit slides on Deck, or a PlanIt cell). Leave the field or change period — the draft still saves. Same date and period chip on both screens.

  • PlanIt is the week grid (periods × days). Send this hour copies onto empty slots only.

7. Rosters

Import

CSV or paste: Last, First, Period. The desk mints a locked id, then a wall alias. Legal names, IEP, and 504 are not stored.

  • Same legal first+last already used to mint an alias → skip add, keep that alias and id.
  • New name → new id + new alias, then the legal name is dropped.
  • A named snapshot “Before roster import” is stored on this device first.
  • Print Shop IDs / Download Shop IDs lives on Records → Roster or Backups. Period, Shop ID, Alias.

What rides in the cloud pack

Students (Shop ID + alias), crews, marks, skills, projects, teach days, prints catalog, club file. Layout, theme, PIN, and Fake data toggle stay on this browser. Deck slides are generated from Teach, not a second copy.

8. Themes and wall looks

Admin → Theme (PIN). Default stays dark (navy / cyan). Never a white wall.

  • Wall looks (one tap): Shop, Back row, Night shop, Oswego, Scoreboard, Club night, Projector, Harvest. Each chip shows a mini wall. Color + type + scale + two-column grid.
  • Brand chips include TechWorks, Bearcat paw, ROLL THE DICE, Night Shift, Ink, Pine, Oswego.
  • Holiday: Holly, Frost, Harvest, Spooky, Patriot, Clover, Wrapping, Valentine, Pumpkin.
  • Day / ADA: Daylight, Manila, Polar. High vis / Contrast sit on top of any theme.
  • Hover a chip to preview (mouse). Tap to apply (Chromebook). Custom saves are custom: ids in techworks-custom-themes-v1.
  • Storage: techworks-theme-v4, techworks-look-v4, techworks-wall-preset-v1. Not in the cloud pack.

Look chip size (--ui-chip) is for wall plates. HUD buttons stay 2.75rem. Gadget shine on header.desk-chrome is not a hit target. Chromebook: no blur stacks on chrome.

10. Fake data

Admin → Modules → Fake data chips: Off / One week / One cycle / Messy cycle. Overlay only. The saved roster stays day 0. A gold chip reads Fake data · not saved.

Turn Off before importing real names.

11. How you will not lose Monday

  • Empty PC + cloud roster → the desk pulls. It will not auto-push zeros over names.
  • This PC has names + cloud is empty → the desk pushes.
  • Push now on 0 workers → a confirm box. Cancel if the cloud should keep names.
  • Storage full → a red flash. Download a full backup before you close the tab.
  • One writer: the shop PC. A second computer is a reader unless you meant to move the room.

This app does not store legal names, IEP, or 504. Projector, embed (?embed=1), this PC, the cloud desk, and the Google book are Shop ID + alias only.
