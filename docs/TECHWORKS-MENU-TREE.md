## 1. DASHBOARD  (projector all day)

Submenu:

```
Wall     Week     YTD     Polls*     Data
```

### Wall (Overview)

On-the-fly **Layout** rail (unlocked): fold / reorder rows.

```
Now ………… live period, time left, visit OPEN/MEETING/CLOSED/SUB
Schedule …… all bells; P6 shows; past periods grey, still tappable
Goals ……… today’s project + one “do this now” line + crews
Modules …… feature cards (Club, Hall, Prints…)
Tools ……… timer, name picker, Ambient Chaos (if on)
Announce … collapsed under goals; always available
School …… top 10 by XP (default) · skills + perks together
```

Cleanup last 5 minutes **overrides Wall only** (not Teach / Learn / Admin).  
Berty points at jobs. Workshop vs classroom. Cleanup cash, not XP.

### Week
Six Tech classes (not Study Hall). Race on earned vs possible as of yesterday. Gold shop lead and first crew. Today = project · activity · assignment.

### YTD (Year)
Session archives, XP / $ totals, “SCHOOL” top ten.

### Polls *
Live vote on the wall. Teacher opens from Teach or Dash.

### Data
```
Live | Archive (last year)
Mix-in Study Hall (opt-in, trends only)
Metric: XP | wallet | stock
Group: worker | period
Chart: bar | line
Sort
Copy: log · master · ledger (Sheets TSV)
```

\* Feature flag (Admin → Modules).

## 3. LEARN  (grades, not daily pay)

Submenu (chips you can hide when unlocked):

```
Book     Projects     Skills     Words     Guide
```

### Book (gradebook)
One **project column** per student + session mark.  
Override / revert. Classroom CSV. Assignment names = project titles.

### Projects
Library (left) · editor (right).  
Activities, phases, skills, start–end, assign to crew/cycle.

### Skills
Workshop | Soft. 1–4 (Beginning → Distinguished). XP / level.  
Not wallet.

### Words
Glossary (shop vocabulary).

### Guide
Benchmarks · class means · NY Tech / Standard 5 (if module on).
