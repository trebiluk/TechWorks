0. Monday live test

Use the shop PC that will stay in the room. Phone browsers are a preview, not the gradebook.

  1. Unlock. Admin → Modules → Fake data Off (gold chip gone).
  2. Admin → Records → Snapshot now “Before Monday roster”.
  3. Records → Cloud → mint / confirm the desk key. Write it in the planner. Not the PIN.
  4. Tap Save on Cloud so the empty-or-current desk is on the internet.
  5. Download JSON desk backup and Google book. Put both in a private Drive folder. Google book is an archive spreadsheet — it does not sync live.
  6. Records → Names / Add a class: paste Last, First, Period. Same legal name keeps the alias. Do not paste twice expecting a merge of aliases — the second pass skips duplicates.
  7. Snapshot again “After P1 import”. Cloud Save. Download JSON.
  8. Open the wall: aliases only. Open a profile with PIN: legal name in the vault, not on the projector.

If a second computer shows 0 workers, do not Save Cloud from that computer. Pull with the desk key, or restore a snapshot on the shop PC.

2. Rosters

Import

CSV or paste: Last, First, Period, optional IEP / 504. The desk mints a locked id, then a wall alias. Legal names never become the projector name.

  • Same legal first+last already on the desk → skip add, keep that alias and id, update period/flags if the file says so.
  • New name → new id + new alias.
  • Manual add, then later CSV of the same people → they keep the aliases you already showed the class.

What rides in the cloud pack

Students (aliases + vault legal names), crews, marks, skills, projects, day plans, prints catalog, deck slides, club file. Layout, theme, PIN, and Fake data toggle stay on this browser.

3. Fake data

Admin → Modules → Fake data, then One week / One cycle / Messy cycle. Overlay only. The saved roster stays day 0. A gold chip reads Fake data · not saved.

On an empty desk, Messy draws a throwaway Forge / Volt shop (ids demo-…) onto the wall, week, year, crews, and data. Those workers cannot be written to disk. Turn Off before importing real names.
