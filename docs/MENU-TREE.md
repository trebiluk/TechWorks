# TechWorks menu tree

Live desk **v1.80.80**. Default chrome is **Nav v2** (top sections + submenu). Classic mode is Dashboard / Desk / Learn / Admin.

Legend: **PIN** = teacher lock. **Wall** = projector-safe. **Mod** = can be turned off in Admin → Modules.

---

## Always-on chrome

- **TECHWORKS** logo → FERPA dash (Overview wall)
- **Find** → alias search → profile (PIN for full info)
- **NOW P# mm:ss** → jump to live period
- **Wall / Phone** surface toggle
- **Lock** → Set teacher PIN (teacher) / Crew lead pad (crew)
- **Help** (?)
- **Berty** peek (mod)
- **Version chip** (v1.80.80)
- Cleanup coral takeover — **Overview only** (not Teach / Learn / Admin)

Overlays (not pages): PIN pad · Worker profile · Help · Cleanup wall · Crew-lead lock

---

## 1. DASHBOARD  (wall)

Submenu: **Wall · Week · YTD · Polls · Data**

### Wall (Overview)
Rows (fold / reorder when unlocked):

1. **Now** — period clock, visit OPEN/MEETING/CLOSED/SUB, weather
2. **Schedule** — P1–P10 strip (P6 shows time only; study-hall data stays out)
3. **Goals** — project name, one “do this now” line, stage, Score
4. **Modules** — feature cards (hidden by default)
5. **Tools** — timer, picker, polls (hidden by default)
6. **Announce** — collapsed announcements
7. **School** — top 10 XP / perks, cycle-quarter-year rings

Cleanup 5:00 → full cleanup wall (jobs, Berty, bonus cash). Tools toggle on header.

### Week
Race: classes vs classes, crews vs crews, earned vs possible as of yesterday. Gold shop lead / first crew. Today strip = project · activity · assignment. Classes / Roster tables still there. Not study hall.

### YTD (Year)
Session bars, archive, next-roster note.

### Polls  *(mod)*
Live vote on the wall.

### Data
Graphs, archive last-year, mix-in study hall toggle (opt-in, does not contaminate class effort).

## 2. TEACH  *(mod)*

Submenu: **Now · Plans · Score**

### Now
- Period chips P1 P2 P3 P8 P9 P10
- **DO THIS NOW** hero (ENTER / LISTEN / CREW WORK / CLEAN UP)
- Slot grid (bell-timed)
- Tools / Polls
- **Pad** (PIN, collapsed by default) → Slots · Tools · Packs · Objective  
  Lesson shape: Shop · Demo · Critique · Training · Short · Sub

### Plans
Date picker · week chips · period × grade grid · click to assign / clear a lesson for that day.

### Score
Same as Desk → Check-in (Teach houses daily scoring).

---

## 3. LEARN

Submenu (chips you can hide): **Book · Projects · Skills · Words · Guide**

### Book
Gradebook. One column per **project**. Session mark. Classroom CSV. Overrides (PIN).

### Projects
Library (drag titles into grade categories). Activities, stages, crew assignment, current vs goal phase.

### Skills
Workshop / Soft family. 1–4 marks (Beginning → Distinguished). Crew-by-crew like Evaluate. PIN to edit.

### Words
Glossary (shop vocabulary).

### Guide
Pedagogy / Standard 5 / Portrait of a Graduate notes.

---

## 4. OTHER

Submenu (each *mod* except as noted):

### Club / Club wall  *(mod)*
- Wall: activity timer · competitions · events · stations · late bus · overlay (card chips)
- Desk (PIN): roster, IN ($10 + 2 XP once/day), stations, dismiss, calendar, Club store (separate)
- Cleanup 3:00–3:05 on the Club wall

### Study hall / Hall wall  *(mod)*
- Hall wall (age-10, productive/peaceful) · line leader game
- Manager (PIN): A/B roster, where they went (nurse, library, teacher, testing…), owes work, notes from Grade 5
- Not mixed into Tech effort unless Data → mix-in is on

### Prints  *(mod)*
Gallery, inventory, small/medium/large, shiny/rare, trades.

### Stocks  *(mod)*
Separate game. Invest from scoring (lead asks, you approve). DJIA / teacher shock. Top-3 picks.

### Lucky Bench  *(mod)*
Die + Friday pot. Class cash only.

### Store  *(mod)*
Perk chips from Config lists. Wallet cannot go negative.

## 5. DESK  **PIN**

Submenu: **Check-in · Crew**

### Check-in (Score)
VERIFY / SCHEDULE / CONFIG modes. 2×2 crew grid. Codes 3 / 2 / 1 / Absent / Excused / Personal. Cleanup, Assist (PIN), Invest ask. SUB locks the pad for that day.

### Crew
Crew manager: daily groups, history, Separate (roster rule), lead for the cycle, crew profile (lead may edit).

## 6. ADMIN  **PIN**

Submenu: **Today · Crews · Look · Day · Roster · Class · Modules · Device**  
(Classic Settings also has **About**. Lunch and Privacy live under Day / Roster.)

### Today
My day card · SchoolTool (8:15) · past-due crews · current class · Score jump · meetings · SUB

### Crews
Same Crew desk as Desk → Crew.

### Look
Theme (Solvay dark default) · theme editor (save custom) · contrast · fonts · vibes as full themes · Nav v2 toggle · board card show/hide · wall/phone

### Day
Bell pack (Regular / 1-hr / 2-hr / Half) · specials / assemblies · A/B day · SUB · visit OPEN/MEETING/CLOSED/SUB · lunch · cleanup minutes ±1 · cleanup sound · default Teach pack · current cycle

### Roster
Year book: 24 Tech sections (P1, P2, P3, P8, P9, P10 × Q1–Q4) + Study Hall + Tech Club.  
Filters: All · Live · Q1–Q4 · Club · Hall · Hold.  
Hold club kids on a worker id (skills persist). Place into a future class. Import names (vault). Portal PIN.

### Class
Pay rates · shop lists (snacks, leisure, chores) · skill lists · class rewards (per period) · levels/XP bands

### Modules
On/off for every extra: weather, Berty, Teach, Polls, reward, tips, contrast, ambient, picker, timer, grades export, crews, store, prints, stocks, lucky, study hall, club, portal, achievements, NY Tech, projects, fake data

### Device
Local save / export / import / restore / backup. Names vault export. Live wall export (encoded). About / copyright.
