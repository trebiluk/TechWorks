0. Monday live test

Use the shop PC that will stay in the room. Phone browsers are a preview, not the gradebook.

  1. Unlock. Admin → Modules → Fake data Off (gold chip gone).
  2. Admin → Records → Snapshot now “Before Monday roster”.
  3. Records → Cloud → mint / confirm the desk key. Write it in the planner. Not the PIN.
  4. Tap Save / Push now on Cloud so this PC is on the internet. If this PC shows 0 workers and you already have names in the cloud, Pull — do not Push.
  5. Download JSON desk backup and Google book. Put both in a private Drive folder. Google book is an archive spreadsheet — it does not sync live. Open with File → Open in Drive as a Sheet.
  6. Records → Names / Add a class: paste Last, First, Period. Same legal name keeps the alias. A snapshot is taken first. The desk writes to this PC immediately.
  7. Snapshot again “After P1 import”. Cloud Save. Download JSON into the same Drive folder.
  8. Open the wall: aliases only. Open a profile with PIN: legal name in the vault, not on the projector.

If a second computer shows 0 workers, do not Push. The desk will refuse to auto-overwrite a cloud roster with an empty PC. Pull with the desk key, or restore a snapshot on the shop PC.

3. Rosters

Import

CSV or paste: Last, First, Period, optional IEP / 504. The desk mints a locked id, then a wall alias. Legal names never become the projector name.

  • Same legal first+last already on the desk → skip add, keep that alias and id, update period/flags if the file says so.
  • New name → new id + new alias.
  • Manual add, then later CSV of the same people → they keep the aliases you already showed the class.
  • A named snapshot “Before roster import” is stored on this device first.

What rides in the cloud pack

Students (aliases + vault legal names), crews, marks, skills, projects, day plans, prints catalog, deck slides, club file. Layout, theme, PIN, and Fake data toggle stay on this browser.

4. Fake data

Admin → Modules → Fake data chips: Off / One week / One cycle / Messy cycle. Overlay only. The saved roster stays day 0. A gold chip reads Fake data · not saved.

On an empty desk, Messy draws a throwaway Forge / Volt shop (ids demo-…) onto Wall, Week, Year, Score, Crews, Learn, Wallet, Rosters, Cleanup, and Data, with project slots on each period. Taps on those boards do not write marks or names. Turn Off before importing real names.

5. How you will not lose Monday

  • Empty PC + cloud roster → the desk pulls. It will not auto-push zeros over names.
  • This PC has names + cloud is empty → the desk pushes.
  • Push now on 0 workers → a confirm box. Cancel if the cloud should keep names.
  • Pull on a full PC against an empty cloud → refused. This PC keeps the roster.
  • Storage full → a red flash. Download a full backup before you close the tab.
  • Clear workers → snapshot first. Restore from Records → Named snapshots.
  • One writer: the shop PC. A second computer is a reader unless you meant to move the room.
