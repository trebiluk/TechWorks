1. Canon

TechWorks is a local-first classroom desk for Solvay middle-school Technology. Google Sheets (or a desk backup file) is the archive. The projector is a FERPA wall. The phone is a tap pad.

  • One version string: src/lib/version.ts → chip, footer, Help, this manual.
  • Repo (source, empty roster): github.com/trebiluk/TechWorks
  • Default theme: Solvay purple–blue (#06122B / accent #22D3EE). Paw orange is Bearcat/seasonal only.
  • Logo lockup: public/brand/techworks.png — rectangle, immune to theme.

5. Gradebook

One grade per project per student. Each activity averages its own 3/2/1 days (100 / 85 / 70) plus that activity’s skill (4/3/2/1 → 100 / 90 / 85 / 70). Project grade = mean of activities. Only days on the crew assigned that cycle count. Wallet, PTO, and shop do not enter the mark.

Family sheet (profile → Family, print): alias or legal name (PIN), course, one %, letter, skill words, days present. No IEP, no 3/2/1 codes, no $.

6. Teacher day

  1. Open Dashboard on the projector. Set daily goal from project phase (or Cycle Config).
  2. P1 by 8:15: SchoolTool chip / banner. Attendance is SchoolTool, not this app.
  3. Crew lead scores 3/2/1 on the pad (live period only; override PIN for other periods).
  4. You verify on Desk / Admin Today. Bonus / deduct / clutch in $5. Assist $10 needs PIN.
  5. T−5 min: coral cleanup wall. Berty points at Workshop vs Classroom jobs. Catch extra = cash, not XP.
  6. Between bells: Berty points at ENTER → LISTEN → CREW WORK → CLEAN UP.
  7. SUB locks scoring for that day; next school day continues the cycle.
  8. Export live wall (aliases) when prompted; desk backup (private) from Admin → Device.

Bells: Regular / 1-hour / 2-hour / Half. Periods 1, 2, 3, 8, 9, 10 are Tech; P6 is Study Hall (own wall, own store, never mixed into class effort unless Data → Mix).

8. Privacy (FERPA)

  • Wall, embed, portal: aliases + public handle. No last names, no student numbers, no IEP.
  • Legal names only after teacher PIN, in Roster fold / family print if you choose names.
  • Live export ≠ desk backup. Restoring the wall file will not restore names.

9. Rebuild in a pinch

  1. Clone trebiluk/TechWorks or unpack a desk source zip. npm install && npm run dev (port 8080 in this sandbox).
  2. Restore a desk backup (Admin → Device), not the live wall JSON.
  3. Stack: React 18 · Vite · Tailwind v4 · TanStack Router. Client-only mount.
  4. Do not paste the workshop 2.1.0 zip over this tree.

Style: HUD corners (.tw-hud), gadget plates (.tw-gadget), hard 2px press rings, solid scrims (no backdrop-filter), no white-flash hovers. Cleanup = coral. Admin edit = red field rings, not a red page.
